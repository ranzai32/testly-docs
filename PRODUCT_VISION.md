# Testly Product Vision

## English

### Product vision statement

Testly is a multiplatform no-code desktop application that enables manual QA engineers and small development teams to create, maintain, and run end-to-end automated tests without programming. By recording browser actions as readable, Git-versioned `.flow.yaml` scenarios, Testly brings UI, API, and database checks into one workflow, protects secrets, simplifies failure diagnosis, integrates with CI/CD, and avoids vendor lock-in through Playwright export.

### Elevator pitch

Testly turns browser interactions into readable automated tests without requiring code. Teams can store tests in Git, run them in CI/CD, diagnose failures with screenshots and logs, and export them to Playwright, making reliable test automation accessible, secure, and maintainable.

## Қазақша

### Өнімнің стратегиялық тұжырымы

Testly — manual QA мамандары мен шағын әзірлеу командаларына бағдарламалау дағдыларынсыз end-to-end автоматтандырылған тесттерді құруға, сүйемелдеуге және іске қосуға мүмкіндік беретін көпплатформалы no-code desktop қолданбасы. Ол браузердегі әрекеттерді оқуға ыңғайлы әрі Git арқылы нұсқаланатын `.flow.yaml` сценарийлеріне айналдырып, UI, API және дерекқор тексерулерін бір жұмыс үдерісіне біріктіреді, құпия деректерді қорғайды, қателерді талдауды жеңілдетеді, CI/CD жүйелерімен бірігеді және Playwright форматына экспорттау арқылы бір платформаға тәуелділікті азайтады.

### Elevator pitch

Testly браузердегі әрекеттерді код жазуды қажет етпейтін, түсінікті автоматтандырылған тесттерге айналдырады. Командалар тесттерді Git-те сақтап, CI/CD ішінде іске қоса алады, скриншоттар мен логтар арқылы ақауларды тез анықтайды және сценарийлерді Playwright форматына экспорттайды — осылайша тестілеуді қолжетімді, қауіпсіз әрі сүйемелдеуге ыңғайлы етеді.

## Русский

### Видение продукта

Testly — это кроссплатформенное no-code desktop-приложение, которое позволяет manual QA-инженерам и небольшим командам разработки создавать, поддерживать и запускать сквозные автоматизированные тесты без навыков программирования. Приложение преобразует действия в браузере в понятные и версионируемые через Git сценарии `.flow.yaml`, объединяет UI-, API- и database-проверки, защищает секреты, упрощает диагностику сбоев, интегрируется с CI/CD и снижает зависимость от платформы благодаря экспорту в Playwright.

### Elevator pitch

Testly превращает действия пользователя в браузере в понятные автоматизированные тесты без написания кода. Команды могут хранить тесты в Git, запускать их в CI/CD, быстро находить причины сбоев по скриншотам и логам и экспортировать сценарии в Playwright, получая доступную, безопасную и удобную в сопровождении автоматизацию тестирования.
